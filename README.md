# Cbrnr Tap

## How do I install these formulae?

`brew install cbrnr/tap/<formula>`

Or `brew tap cbrnr/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "cbrnr/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
